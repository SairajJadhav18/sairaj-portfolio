# Detailed race car update

Eight original, procedurally modeled open-wheel cars replace the earlier rounded-box cars. Each includes tapered noses, sculpted sidepods, layered wings, a driver helmet, halo, exposed tires with rims, and suspension struts. The starting lights, grandstands, crowd animations, flashes, confetti, and scroll-linked launch are unchanged.

No external car models or copyrighted liveries are included.

Run `npm install` then `npm run dev`. A production build could not be completed in this environment because dependency installation timed out.
