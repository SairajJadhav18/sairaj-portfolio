# Pixel: interactive 3D-inspired robot contact assistant

Replaces the earlier cartoon robot with an original SVG-based, 3D-inspired rounded desktop robot based on the user's white-and-pink reference.

- Cursor-driven pupil and head movement
- Gentle idle bob and animated arm wave
- Blinks every few seconds
- Expression and speech-bubble changes when focusing the contact form or hovering social links
- Cheerful animation on form submit
- Reduced-motion CSS support
- No extra dependencies and no React Three Fiber/Drei HTML overlay
- Form still uses mailto and does not directly submit messages to a server
