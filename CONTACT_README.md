# Robot dog contact section

The contact section now uses an SVG robot dog (Pixel) whose pupils track pointer movement. It includes a validated name/email/message form that opens the visitor's email app using `mailto:`; this is intentionally not a server-side contact form. To receive submissions directly from the website without relying on a visitor's email app, configure a mail API or form backend with spam protection and privacy handling.
